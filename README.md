# Лесной дозор

Демонстрационный одностраничный сайт по раннему обнаружению лесных пожаров в Казахстане.

## Запуск
Откройте `index.html` в современном браузере. Сервер и зависимости не требуются.

Все участки, координаты, события и статусы вымышлены. Макет не предназначен для оперативного управления.
